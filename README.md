## 内容

uni-app 多端商城小程序（微信/支付宝/百度/字节/QQ/H5/App）：

- 5 个 tabBar 主页面：首页 / 分类 / 逛逛 / 购物车 / 我的
- 100+ 分包页面：商品、订单、商户、会员、分销、活动、工作台等
- 统一请求层（utils/request.js）：三 token 按 URL 自动选择
- 多商户上下文（merId / selectMerId / merchantEmployeeList）
- 313 个前端 API 路由
